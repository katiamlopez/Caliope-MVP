# Minuta - Estructura de Navegación y objetos

**Tipo de reunión:** Seguimiento de desarrollo de interfaz
**Fecha:** [26-06-2026]
**Proyecto:** Caliope (MVP)
**Equipo:** MichiScript

## Objetivo de la reunión

Diseñar e implementar la estructura de navegación de la aplicación mediante un menú lateral funcional que permita el acceso a las distintas secciones desarrolladas del sistema, así como avanzar en el modelado de datos de la aplicación.

## Temas tratados

### 1. Definición de la estructura del menú

Se estableció la organización y jerarquía de las opciones de navegación, considerando las páginas desarrolladas: Inicio de Sesión, Registro, Página Principal, Nosotros y Contáctanos.

### 2. Desarrollo de la estructura HTML

Se implementó la estructura base del menú lateral utilizando etiquetas HTML para garantizar una navegación clara y organizada.

### 3. Diseño visual del menú

Se aplicaron estilos para mejorar la apariencia del menú, definiendo distribución, iconografía y estados visuales de los elementos de navegación.

### 4. Implementación de funcionalidad interactiva

Se desarrolló el comportamiento desplegable y colapsable del menú, permitiendo optimizar el espacio de trabajo y mejorar la experiencia de usuario.

### 5. Configuración de rutas de navegación

Se enlazaron las opciones del menú con las páginas correspondientes para facilitar el desplazamiento entre las diferentes secciones de la aplicación.

### 6. Adaptación responsiva

Se realizaron ajustes para asegurar el correcto funcionamiento y visualización del menú en distintos tamaños de pantalla.

### 7. Modelado de objetos en JavaScript

Se desarrollaron las estructuras base de los objetos **Usuario** y **Libro** utilizando JavaScript, definiendo los atributos necesarios para representar la información principal que será utilizada en el sistema.

## Acuerdos generales

* Mantener una estructura de navegación consistente en todas las páginas.
* Continuar integrando nuevas secciones al menú conforme avance el desarrollo.
* Verificar periódicamente el correcto funcionamiento de las rutas de navegación.
* Continuar ampliando el modelado de datos según los requerimientos del proyecto.
* Aplicar mejoras de diseño y usabilidad según las necesidades del proyecto.

## Conclusión

Se completó la implementación inicial del menú lateral de navegación, incluyendo su estructura, diseño, funcionalidad interactiva y conexión con las páginas desarrolladas. Adicionalmente, se avanzó en la construcción de la base lógica del sistema mediante el modelado de los objetos Usuario y Libro en JavaScript, sentando las bases para futuras funcionalidades del proyecto Caliope.
